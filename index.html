Pitch round

Five daily word games. One of them is yours.

A golf course, a laboratory, a tray of sliding letters, a word that grows, and a paragraph with something hidden in it. One shared kit, five different products — all five finished, and playable on a phone right now.

lightbulb“I was clever.” A line nobody else found, and you want the credit.
sentiment_dissatisfied“I was SO close.” A near miss that stings enough to need witnesses.

Nobody posts a result for any other reason. Each game below is engineered to manufacture one of those two, daily, and to leave six pasteable lines that tell the story without leaking the answer.

For the reviewer

today
A puzzle a day, never a lockout

The local date sets which board everyone opens on. Finishing one — won or lost — hands you the next immediately, so you can play four in a row.

link
Pin any puzzle

Add ?d=4 to any game's URL to open that exact board. Numbering is stable, so a whole committee can review the same one.

touch_app
Mobile first, thumb only

Every game plays start to finish inside a 390×844 viewport with 44px targets. Then again on desktop, with a physical keyboard.

bolt
No build step

Static HTML, CSS and JS. Opens straight from file:// or over http. No frameworks, no CDNs, no network at all — the type is inlined.

verified
Hand-authored, then checked

Each game ships six or more puzzles plus its own verify.js — every board machine-checked, and hand-solved, before it shipped.

share
An answer-safe artifact

Every result copies six lines or fewer that read in iMessage, tell the story at a glance, and give nothing away.
